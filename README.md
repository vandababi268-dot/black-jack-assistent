# black-jack-assistant
🃏 Your Ultimate Blackjack Assistant  Take your blackjack game to the next level with our powerful browser extension.

### 🛠️ How to Install the Blackjack Assistant

#### 1. Install the Extension

**Google Chrome:**

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the **`dist`** folder from the extension files.
5. The extension will now appear in your extensions list.

The same process can be used in **Opera** and **Brave** through their extension management pages.

#### 2. Open Stake

1. Go to **Stake.com** and open the Casino section.
2. Launch a supported blackjack game.
3. Once the game loads, the Blackjack Assistant will automatically appear on the page.

That's it — the assistant is now ready to use.
